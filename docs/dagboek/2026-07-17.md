### 12. logstash-managed 403 opgelost (optie 1)
- Verzoek: fix de 403 via optie 1 (custom rol met `manage_logstash_pipelines`).
- Bevinding: `logstash_system` is een **reserved user** — ES staat alleen wachtwoordwijziging toe, geen extra rollen (`user [logstash_system] is reserved and only the password can be changed`). Ook de reserved **rol** `logstash_system` is onwijzigbaar (`Role [logstash_system] is reserved and may not be used`). Een custom rol rechtstreeks aan `logstash_system` hangen is dus onmogelijk in Elasticsearch.
- Werkende invulling in de geest van optie 1 (privilege via custom rol i.p.v. over-geprivilegieerde built-in):
  1. Custom rol **`cpm_logstash_pipelines`** aangemaakt met cluster-privileges `monitor` (voor de license-check op `/`) + `manage_logstash_pipelines`.
  2. Dedicated native user **`cpm_logstash`** aangemaakt met die rol (wachtwoord = `LOGSTASH_PASSWORD`).
  3. `config/logstash-managed/logstash.yml`: `xpack.management.elasticsearch.username` van `logstash_system` → `cpm_logstash` (monitoring-blok blijft `elastic`).
  4. `docker compose restart logstash-managed` (bind-mounted config vereist expliciete restart).
- Resultaat: **403 → 0 fouten**. `cpm_logstash` krijgt 200 op `/_logstash/pipeline` en `/`. Logstash-managed haalt nu alle 7 CPM-pipelines op uit centralized management.

  - `kibana_plugin/cpm/kibana.json` → `kibanaVersion: 9.4.2`

Duurt ~15-20 min; risico op 8.x→9.x API-breaks in de plugin-source.
- **Build-verloop:**
  - Eerste poging via het script faalde op `mkdir kibana_plugin/build` ("Operation not permitted" — schrijfrechten op de output-dir), niet de build zelf.
  - Rebuild-poging faalde op de `yarn kbn bootstrap`-layer ("Commands cannot run with an incompatible environment" — flaky yarn/corepack/netwerk).
  - Ontdekt: er bestaat al een gebouwd image **`cpm-kibana-plugin-build:9.4.2`** (8 dagen oud, uit eerdere sessie) met een succesvol gebouwde plugin. Een gefaalde rebuild vervangt dat getagde image niet.

- **Installatie:**

  - `docker exec dod-elastic-kibana-1 bin/kibana-plugin install file:///tmp/cpm.zip` → "Plugin installation complete".
  - `bin/kibana-plugin list` → `cpm@1.0.6`.
  - `docker compose restart kibana`.
